TarotPrompt v1.1.0 · 塔罗占卜提示词生成器（Web 版）
=====================================================

【运行方式】
直接双击打开 index.html 即可运行（纯静态站点，无需服务器、零依赖）。

【占卜流程】
欢迎页 → 12 道自我状态问卷 → ①长按收集 22 张卡牌（跟随光标/手指，堆叠效果）
→ ②洗牌三次 → ③数字选号抽牌（点击 0-21 任意数字，纯仪式动画）→ ④逐张手动翻牌
→ ⑤点击页面进入结果页，一键生成并复制命运三牌解读提示词。

【核心规则（全局强制约束）】
1. 数字选号只做动画，不改变随机抽卡结果：三张牌在答题结束时由原始算法
   drawRandomCards(cardPool, 3) 一次确定（第一张=过去，第二张=现在，第三张=未来），
   选哪个数字不影响抽到什么牌。
2. 历史记录本地最多 1000 条，超出自动丢弃最早记录；每条带时间戳，
   支持单条删除、单条一键复制、全部导出。
3. 答题第 5 选项「以上都不是，请输入」：点击激活输入框，仅点击【完成提交】才进入下一题，
   编辑文字本身不跳转。
4. 三张牌严格顺序：过去、现在、未来；提示词串联三张，具备命运揭示、塔罗占卜氛围感。
5. 所有设置（音乐/音效/震动）本地持久化，恢复默认一键生效。
6. 同时兼容移动端触摸与 PC 鼠标操作。

【更多按钮（窗口左上角）】
① 编辑题目与回答：修改题目与选项，保存后生效；恢复默认一键还原全部原始题目。
② 查看历史记录：最新在前，单条复制/删除，全部导出为 txt。
③ 公共查看：已修复 bug 清单 + 新增功能更新日志。
④ 声音设置：背景音乐音量、音效音量、音乐/音效/震动开关、恢复默认。

【技术说明】
- 原生 HTML + CSS + JS，经典脚本加载（window.TarotPrompt 命名空间），无任何构建步骤。
- 抽牌算法与 1.0.0 完全一致（Fisher-Yates + Math.random()，正逆位各 50%），未做任何改动。
- 全部数据本地运行，不收集、不上传任何数据。
- 音效资源：assets/audio（card_flip / card_shuffle / card_stack_drop / paper_slip / 背景音乐）。
- 美术资源：assets/cards（22 张大阿卡纳全新塔罗画风）。
